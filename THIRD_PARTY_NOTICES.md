# Code tiers

Les dossiers suivants contiennent l'API BME280 de Bosch Sensortec v3.5.1 :

- `tp03_i2c/main/` ;
- `tp09_uart_protocol/main/` ;
- `tp11_bench_controller/main/` ;
- `tp11_5_integration/bench_integrated/main/` ;
- `tp11_5_integration/dut_integrated/main/` ;
- `tp16_5_final_integration/bench_final/main/` ;
- `tp16_5_final_integration/dut_final/main/`.

Dans chaque dossier, les fichiers concernés sont `bme280.c`, `bme280.h` et `bme280_defs.h`.
